
# Mini Project 2 Proposal: Fresh'd

## What I Am Building
I want to build Fresh'd, an interactive virtual fridge that helps users keep track of the food they have, organize their groceries, and know what to use before it expires.

## Who It Is For
This is for people like me who sometimes forget what food they already have in their fridge. It can be annoying to buy something twice or find ingredients that have already expired. I want to make managing food more visual, organized, and fun.

## What It Remembers
- Food names and quantities
- Expiration dates
- Where each food item is placed in the fridge
- The user's fridge organization and customization

## Where the Data Lives
The data will be stored in JavaScript and saved using localStorage so it stays there even after refreshing the page.

## What Each Action Changes
- Add food: Adds a new product to the fridge inventory.
- Move food: Updates which shelf or compartment the product belongs to.
- Edit food: Updates its name, quantity, or expiration date.
- Delete food: Removes the product from the inventory.
- Open fridge: Changes the view from the closed fridge to the inside.
- Reset: Clears the inventory and returns the fridge to its empty state.

## Features
1. An interactive refrigerator that users can open and close.
2. A customizable fridge with magnets and decorations.
3. The ability to add and organize food on different shelves.
4. Expiration tracking that shows which products should be used soon.
5. Food inventory saved between visits.

## What I Do Not Know Yet
- How to create a realistic fridge-opening animation using JavaScript and CSS.
- How to make food items draggable between shelves.
- How to save and retrieve data using localStorage.
- How to automatically calculate expiration dates and update the page.
